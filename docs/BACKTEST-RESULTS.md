# ROZLF AI — نتائج الاختبار التاريخي (Walk-forward)

- المصدر: Yahoo Finance FX (بيانات فوركس حقيقية متأخرة، بدون مفتاح).
- كل قرار يستخدم الشموع المغلقة حتى لحظة القرار فقط، والدخول عند إغلاق الشمعة التالية (latency=1 bar).
- الانتهاء يحسب عند أول شمعة تغلق بعد وقت الانتهاء الفعلي.
- لا يوجد تحسين للمعاملات: كل النتائج out-of-sample بالنسبة لمجموعة القواعد الثابتة.
- العائد لكل صفقة وحدة واحدة (+1/-1)؛ النتائج ليست نسبة ربح مضمونة.

## ملاحظات

- العينة صغيرة نسبياً (300 شمعة لكل تشغيل) ولا تكفي للحكم على استراتيجية نهائياً.
- النتائج تختلف جذراً بين الأزواج؛ لا تُعرض نسبة نجاح في البوت قبل وجود نتائج موثقة أعلى حجماً.
